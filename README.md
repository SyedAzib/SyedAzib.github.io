# Syed Azib Portfolio Website

This is a static portfolio website built with HTML and CSS. It needs no paid hosting.

## Publish it free on GitHub Pages

1. On GitHub, create a **public** repository named `SyedAzib.github.io`.
2. Upload `index.html` and `styles.css` from this folder to the new repository.
3. In the repository, open **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. After GitHub publishes it, your site address will be: `https://syedazib.github.io`.

Before publishing, open `index.html` and add your LinkedIn link if you want it displayed.
